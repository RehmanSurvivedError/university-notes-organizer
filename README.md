# 📚 University Notes Organizer

## 📌 Project Overview

University Notes Organizer is a Python CLI application that helps students create, organize, search, and manage their study notes efficiently.  
Each note is stored as a separate text file inside a notes folder.

---

## 🎯 Features

- Create notes
- View a specific note
- View all saved notes
- Search notes by keyword
- Delete notes
- File-based note storage

---

## 🛠️ Technologies Used

- Python 3
- File Handling
- OS Module
- CLI (Command Line Interface)
